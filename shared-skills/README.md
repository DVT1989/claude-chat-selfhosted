# Shared skills

Every folder in `skills/` (a Claude Code skill with a `SKILL.md`) is linked into the Claude Code home of every user.
Optional `hooks.json` here (`{"hooks": {...}}`, Claude Code hook format) is merged into each user's settings.
Optional `MANIFEST.json` describes the skills for the Skills page.

Empty by default. Drop in your own skills or any public skill collection you like.
